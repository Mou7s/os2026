### 2026-09-28：地图文件与内存中的网格

- **本次主题：** `fopen` 打开文件后返回 `FILE *` 文件流；`fgets` 可逐行读入临时字符串。行中的 `\n` 是换行符，C 字符串末尾的 `\0` 是结束标记，两者用途不同。
- **文件与内存：** 地图文件是按行写的文本；程序读入后，把格子字符放进 `Labyrinth.map[row][col]` 这个二维数组。
- **已确认：** `rows`、`cols` 记录实际行数和列数，不是坐标；第一行的格子数确定 `cols`，每成功读入一行，`rows` 增加一。后续行必须与 `cols` 一样宽；少一个格子也要拒绝地图。
- **容量自测：通过。** `MAX_COLS` 为 100 时，100 个格子后遇到真实换行符是合法的；若同一行还有第 101 个格子，应在写入前拒绝，不能自行换行。
- **返回值自测：通过。** `loadMap` 失败时返回 `false`；`main` 应把失败转成非零进程退出码（测试要求为 `1`）。正常成功退出返回 `0`。
- **代码现状：** `loadMap` 仍是 TODO；目前讨论的是需要实现的读取思路。测试中的地图例子可见 `labyrinth/tests.c`。
- **下一步：** 看 `FILE *` 成功打开后，如何在所有结束路径关闭文件，再开始拆解 `loadMap` 的实现步骤。
